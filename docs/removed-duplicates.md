# Removed generated duplicates

On 2026-10-08 the catalogue was cleaned of 296 generated clones. Each was a "Gen N", "Series N", "Mk N", "V N" or "Type N" copy of a product that is still listed (the "Kept product" column), with made-up prices and no manufacturer source. Six similar-looking entries with no base product (Yuba Spicy Curry V3, Trek Rail 5 Gen 3, Tern Vektron S10 Gen 2, Mercane Widewheel Pro V2, Fluid FreeRide Horizon V2, Evolve Carbon GTR Street Series 2) are real model generations and were kept.

The removed entries remain in git history (commit before this change) if any needs to be restored.
