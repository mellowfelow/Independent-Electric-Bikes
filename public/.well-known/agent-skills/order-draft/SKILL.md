# order-draft

Use the order-draft tool of the MCP server at https://independentelectricbikes.com.au/api/mcp/. It returns a prefilled draft only: it never takes payment and never submits an order. The customer completes checkout themselves at https://independentelectricbikes.com.au/checkout/ or over WhatsApp, pays by bank transfer, PayID or crypto, and must send a screenshot of the payment straight away so the order can be confirmed. Minimum order is AUD 350.
